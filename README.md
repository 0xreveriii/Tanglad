# Tanglad

Tanglad is a collaborative project tracker and task balancer that gives tasks a shared weight, reveals workload imbalance, and supports fairer team decisions.

## Landing page stack

- Next.js 16 with React 19
- TypeScript
- Tailwind CSS 4 plus semantic CSS tokens
- Motion for scroll-linked animation and reduced-motion support
- Phosphor Icons
- Locally bundled Manrope and JetBrains Mono variable fonts

## Run locally

From `E:\GitHub\Tanglad`:

```powershell
npm run dev
```

Then open `http://localhost:3000`.

## Validation

```powershell
npm run typecheck
npm run build
```
